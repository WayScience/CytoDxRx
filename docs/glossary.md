# Glossary

- **artifact**: a technical effect on well profiles that is not biology.
- **position effect**: an artifact that is a function of well position.
  **Tilt** is one type (a smooth additive row-plus-column map with a per-layout amplitude); others include control-column offsets, parity patterns and edge effects.
- **covariate effect**: an artifact driven by a measured covariate, such as cell count or confluence.
- **platemap**: the file that says what is in each well.
  A barcode-to-platemap table links plates to platemaps.
  A **layout** is a set of plates sharing the same arrangement.
- **identifiability grade**: whether an artifact can be separated from biology in a design: by design, under an assumption, or not at all.
- **plan file**: the proposed corrections with their evidence; a person approves entries before anything is applied.
