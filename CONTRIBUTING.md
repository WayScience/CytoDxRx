# Contributing

Thank you for your interest in CytoDxRx. Please see the
[development documentation](docs/development.md) for how to set up the environment,
run the tests and build the docs, and for the conventions we follow.

In short:

- Keep pull requests small and focused on one thing.
- Include tests, and documentation for any change in behavior.
- Run `uv run pre-commit run --all-files` before opening a pull request.
- Be kind: see our [code of conduct](CODE_OF_CONDUCT.md).
